# Changelog

## 2.0.0 — 2026-10-26

### Practical resources

- Runnable aiogram 3.31.0 support-bot example with SQLite migrations, persistent drafts, client/operator/admin/owner boundaries, assignment, settings, audit and transactional delivery receipts.
- Explicit polling loop that does not advance the Telegram offset after a failed handler; active webhooks are never removed automatically.
- Token-free CLI smoke exercising the actual aiogram dispatcher and real temporary SQLite, including role revocation, stale callbacks, restart, replay and concurrent assignment.
- Offline validator for five Bot API 10.3 methods, request fixtures and documented approximation boundaries. It is not a server parser or a live rights check.
- Self-contained interactive UX gallery with nine scenarios, light/dark themes and mobile layout. It is explicitly illustrative, not a Telegram client screenshot or security implementation.
- Five domain recipes: booking, support, shop, membership club and publishing.

### Portable package

- Short core skill routes to resources on demand; existing project stacks remain supported.
- Russian and English usage documentation, local checker, deterministic skill/source archives, runtime-state exclusions and bounded credential guards.
- Behavior tests, executable AI application evaluations, near-miss trigger queries and Windows/Linux CI configuration.
- Repository publication, hosted CI, license selection and real Telegram delivery/rendering remain separate explicit steps; this release performs no upload.

## 1.0.0 — 2026-10-26

- Initial skill with eight topical references: discovery, formatting, menus, backend, security/admin, Telegram surfaces, delivery and official sources.
- Guidance distinguishes ordinary messages, rich messages, group-private ephemeral replies and client/account APIs.
- Initial model scenarios and local SDK/dispatcher checks; no live Telegram credentials or sends.
